# TooSquare

"TooSquare" is a game I came up with when I watched a short video regarding Otto Toeplitz and the Inscribed Square Problem (https://en.wikipedia.org/wiki/Inscribed_square_problem).
This conjecture hasn't been proven for all loops so I created a simple game to see if users can find loops that have a perfect square. The current game features line sizes, angles of corners, a rating out of 100 based on how accurate the user creates a square, and 2 game modes. 

I do plan on adding a leaderboard, timer, and some additional features in the near future. Feel free to enjoy it and recommend any changes you think I should make.
